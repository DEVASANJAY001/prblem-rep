# Data Analysis & Decision-Making for Builders

*Stuckhere Academy, Subject 8: turn raw evidence into numbers, charts and decisions you can defend*

## Chapter 0: Course Overview

### 0.1 What This Subject Covers

#### 0.1.1 The one-line idea

Every stage of building, from validating a problem to scoring pain, sizing a market, testing a prototype and tracking a pilot, depends on data. This subject teaches the practical analysis skills builders need to make evidence-based decisions.

#### 0.1.2 What you will be able to do

- Ask answerable questions and choose the right data
- Clean and analyse data in spreadsheets, SQL and Python
- Use basic statistics without being fooled by noise
- Design surveys and analyse interviews systematically
- Build weighted scoring models such as a Pain Score
- Run simple experiments and read funnels and retention
- Present findings clearly and honestly
